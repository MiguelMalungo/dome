# D’OME — website

Bilingual (PT/EN) site for D’OME wooden geodesic domes, built with [Astro](https://astro.build).

## Run it

Needs Node.js 22.22 or newer (`node -v`). On this Mac it is installed with Homebrew as `node@22`; put it first on your `PATH`:

```sh
export PATH="/opt/homebrew/opt/node@22/bin:$PATH"
```

```sh
sh scripts/install-deps.sh   # instead of npm install (iCloud, see below)
npm run dev        # http://localhost:4321
npm run build      # static site in dist/
npm run preview    # serve dist/ locally
npm run photos     # generate the photos with Higgsfield (see docs/images.md)
```

### This folder is in iCloud Drive

iCloud can delete files from `node_modules` once it starts syncing them (it happened here, breaking `npm run dev`). Install the dependencies with this script instead of `npm install`:

```sh
sh scripts/install-deps.sh
```

It installs outside iCloud, moves the result into `node_modules.nosync/node_modules` (iCloud skips `.nosync`) and links `node_modules` to it. Run it again after changing dependencies: a plain `npm install` replaces the link with a real folder that iCloud will sync. To add a package, `npm install <pkg> --package-lock-only`, then run the script.

The simplest long-term fix is to keep the project outside iCloud Drive (e.g. `~/Projects/dome`) and sync it with git.

## Work on it with Claude Code

Open a terminal in this folder and run `claude`. `CLAUDE.md` gives it the project context, conventions and the open TODO list.

## Where things are

| What | Where |
| --- | --- |
| All text (PT + EN) | `src/i18n/ui.ts` |
| Contact details, model specs | `src/config.ts` |
| Photos (optional, replace illustrations) | `src/assets/photos/`, generated by `scripts/photos/higgsfield.mjs` — see `docs/images.md` |
| Dome illustrations | `src/illustrations/` (generated by `scripts/illustrations/render.py`) |
| Logo files | `brand/` |
| Business notes | `docs/business-brief.md` |

## Deploy

Netlify is the easiest: connect the repo (or drag `dist/` in), build command `npm run build`, publish directory `dist`. The quote form uses Netlify Forms, so submissions appear in the Netlify dashboard with no extra setup. Set the real domain in `astro.config.mjs` first.
